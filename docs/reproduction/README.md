# 单卡复现步骤

所有步骤必须先解释、再确认、后执行。完成一个步骤后立即停止，汇报文件、命令和检查结果，等待项目所有者确认下一步。

## 阶段顺序

1. 建立工程骨架与复现契约。
2. 固定、审计官方源代码并建立模块映射。
3. 定义 Python/CUDA 依赖，但不立即训练。
4. 复现数据与时间切分协议。
5. 复现 RQ-VAE 与 Semantic ID。
6. 复现 Qwen2.5-0.5B SFT。
7. 复现 Trie 约束推理与官方评测。
8. 复现 SASRec 教师。
9. 复现官方 ranking-GRPO。
10. 汇总复现偏差并进行基线验收。
11. 经单独确认后进入创新阶段。

每一步文档必须依次包含：原理、研究问题、输入、输出、配置解释、拟执行命令、验收标准、停止条件和常见错误。
