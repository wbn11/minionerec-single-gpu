# 官方复现规格

本文件冻结“复现成功”所指的算法范围。实际配置在对应步骤确认后补充。

## 数据协议

- 数据集：Amazon Industrial and Scientific、Office Products。
- 主结果优先使用官方发布的预处理数据与 SID，以减少原始数据不可得造成的偏差。
- 用户序列按时间切分，最大历史长度为 10。
- 训练、验证和测试目标严格隔离。
- 官方未过滤协议作为复现主协议；过滤已交互商品作为补充协议。

## Semantic ID

- 商品输入以标题和描述为主。
- 文本表示参考官方冻结 embedding 模型。
- 三层残差量化，每层 256 个 code。
- SID 形如 `<a_x><b_y><c_z>`。
- 必须报告 code 使用率、perplexity、死码和完整 SID 碰撞。

## 生成模型

- 单卡主模型为 Qwen2.5-0.5B-Instruct。
- 将三层 SID code 作为专用 token 加入 tokenizer。
- 先复现官方可公开构造的 SFT 任务，再复现 next-item SID 生成。
- 生成结果必须经过合法 SID 目录约束。

## 官方后训练

- 先实现官方 exact/rule 与 ranking reward。
- GRPO rollout group 目标值为 16；若单卡实测超过显存门槛，任何调整必须对所有对照方法一致并记录。
- KL、奖励公式和数据协议不能因为单卡而改变。

## 评测

- 主指标：HR@5/10/20、NDCG@5/10/20。
- 合法生成率必须单独统计。
- 训练采样与确定性评测配置必须分离。
- 任何论文数值只有实际执行后才能写入结果文件或 README。

## 复现验收

复现阶段完成需要同时满足：

1. 数据、SID、SFT、约束生成、SASRec 和官方 GRPO 均有独立模块与配置。
2. 合成单元测试通过。
3. 单 A6000 能从配置启动各阶段，并可断点恢复。
4. 官方 checkpoint 的评测协议已对齐。
5. 所有单卡差异均记录在 `reproduction_diff.md`。
6. 项目所有者明确确认复现完成，才允许加入创新奖励。
